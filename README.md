# SignSpeak: English Sign Language to Voice and Text Translator Using Arduino Uno

## Project Overview
SignSpeak is a low-cost embedded system that translates five predefined English sign language gestures into text and voice output. It uses flex sensors and an Arduino Uno to detect finger bending patterns and identify gestures through predefined threshold values.

## Supported Signs
- Hello
- Yes
- No
- Thank You
- Okay

## Hardware Components
- Arduino Uno R3
- Five Flex Sensors
- CD4051 Multiplexer
- 10 kΩ Resistors
- 16×2 I2C LCD
- DFPlayer Mini
- MicroSD Card and Speaker

## Technologies
- Arduino IDE
- Embedded C/C++
- Threshold-based Gesture Recognition

## Output
The recognized gesture is displayed on the LCD, while the corresponding pre-recorded audio is played through the speaker.
